# Erudoza

Erudoza is a Scripture training app for coaches and students preparing for Bible competitions. Coaches create seasons, choose passages, assign each student a difficulty, manage content and review saved progress. Students study assigned passages through deterministic activities, complete due reviews, rehearse and review their progress. Team Practice adds rooms, invitations, coach-managed questions and team evidence where enabled.

The primary interface should make daily navigation and assignment management quick and understandable. The user selected Option C command-center navigation and a restrained navy, ivory and teal academy theme. It applies to both roles. Keep real data, existing authorization, confirmation behavior and activity rules; do not invent accomplishments from visual prototypes. Use system sans for interface text, serif for Scripture and Erudoza branding. Desktop and mobile are supported.
