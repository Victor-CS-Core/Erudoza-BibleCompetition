# Buy Me a Coffee widget image fixture

`bmc-coffee-cup.svg` is an unmodified copy of the original provider artwork from https://cdn.buymeacoffee.com/widget/assets/coffee%20cup.svg, retrieved September 12, 2026. The offline browser suites use it so screenshots match the real widget rather than an emoji placeholder. It is a test fixture, not a production asset override; the live widget continues to load the original provider URL.
